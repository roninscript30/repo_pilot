# Project Philosophy

Last reviewed: 2026-08-03

## Engineering Philosophy

The project values:

- Simplicity over unnecessary complexity.
- Explicit design over hidden behavior.
- Modular architecture.
- Clear separation of concerns.
- Strong documentation.
- Consistent engineering practices.
- Long-term maintainability.
- Production-quality software.
- Open-source collaboration.
- Extensibility from the beginning.

Every implementation should improve the overall quality of the project instead of only solving the immediate problem.

## Repository Philosophy

The repository should demonstrate professional software engineering practices. Every change should contribute to a maintainable, scalable, production-ready codebase.

The repository itself should serve as an example of good engineering practices across architecture, documentation, testing, code quality, and project organization.

## AI Collaboration Philosophy

AI agents are engineering contributors. They must understand the existing architecture, project memory, and engineering rules before making changes.

When new knowledge is created, agents must preserve it within the memory system so future contributors do not lose context.
