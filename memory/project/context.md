# Project Context

Last reviewed: 2026-08-03

## Intro

Repo Pilot is a modern repository operating platform for software developers and maintainers. Its job is to bring repository management, collaboration, engineering insight, and repository operations into one coherent desktop workspace.

The project should feel like a professional engineering cockpit for repositories: a place where a developer can browse repositories, understand what is happening, collaborate on work, inspect health, and operate delivery workflows.

## What This Project Is

- An open-source engineering workspace for repositories.
- A desktop-first platform for repository management and understanding.
- A GitHub-first MVP with a long-term multi-provider direction.
- A codebase that should model strong architecture, documentation, testing, and maintainability.
- A project where AI agents are engineering contributors and must preserve knowledge in memory.

## What This Project Is Not

- Not another Git client.
- Not another GitHub Desktop clone.
- Not only a repository viewer.
- Not a thin wrapper around GitHub API responses.
- Not a GitHub-only product by long-term design.

## MVP Context

The first version focuses on GitHub. Users authenticate with GitHub and manage repositories from a modern desktop interface.

The MVP exists to establish the engineering foundation and core repository workflows before advanced platform capabilities are added.

## Long-Term Context

The project should grow toward multi-provider repository operations, repository diagnostics, engineering metrics, AI-assisted understanding, architecture visualization, release readiness, plugins, offline repository capabilities, and local Git integration.

## Engineering Standards

Every implementation should favor clarity, modularity, explicit boundaries, maintainability, strong documentation, and production-quality engineering.
