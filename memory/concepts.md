# Project Concepts

Status: Active
Owner: Project Maintainers
Last Updated: 2026-08-06

## Repository Operating Platform

A Repository Operating Platform is a workspace for understanding, managing, operating, and evolving software repositories.

It includes Git workflows, but it is broader than Git. It includes collaboration, release operations, workflow visibility, repository intelligence, diagnostics, and future automation.

## Transparency

Repo Pilot should make engineering operations easier without hiding what is happening. Users should understand the effects of actions before they perform them.

## Provider

A provider is a Git hosting or collaboration service such as GitHub, GitLab, Forgejo, or Gitea.

Providers expose similar concepts with different APIs, permissions, and edge cases.

## Repository Intelligence

Repository intelligence is insight derived from repository structure, history, workflows, issues, pull requests, releases, contributors, dependencies, and health signals.

## Knowledge-First Development

Knowledge-first development means implementation is not complete until durable project knowledge is updated.

## AI Contributor

An AI contributor is an engineering participant that must follow the same standards as human contributors and maintain the knowledge base after meaningful work.
