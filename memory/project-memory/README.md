# Project Memory

Status: Active
Owner: Project Maintainers
Last Updated: 2026-08-06

This directory stores evolving project memory for humans and AI agents.

Project memory is different from reusable skills. Memory records what happened, what is currently true, what remains unfinished, and what future contributors should know.

## Files

- `active-context.md` - current context and near-term focus
- `implementation-log.md` - chronological progress record
- `lessons-learned.md` - durable lessons from work
- `constraints.md` - known constraints and limits
- `technical-debt.md` - tracked debt and cleanup opportunities

## Agent Maintenance Rule

Every meaningful development task should update at least one project-memory file unless nothing durable changed. If no memory update is needed, the contributor should say why.
