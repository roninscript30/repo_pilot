# Engineering Conventions

Last reviewed: 2026-08-03

## Current Repository Conventions

- Use Markdown for project memory files.
- Keep memory pages focused and cross-linked.
- Prefer updating authoritative pages over duplicating facts.
- Add decision records for durable choices.
- Keep root-level files limited to high-value entry points and repository-wide instructions.

## Code Conventions

No application code conventions exist yet. Define them when a language, framework, and tooling are selected.

## Documentation Conventions

- Project memory is not user documentation.
- Use concise headings and tables for scanability.
- Link related pages directly.
- Include "Last reviewed" dates on pages that describe current implementation reality.
- Move lasting insights from agent working memory into the appropriate authoritative area.
