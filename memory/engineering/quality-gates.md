## Required Manual Gate For Now

- Confirm changed memory links are accurate.
- Confirm new knowledge is stored in the correct authoritative location.
- Confirm agent working memory is updated for unfinished work, constraints, or important discoveries.
- Confirm decision records exist for durable architecture or workflow decisions.
