# Skill: Obsidian Vault Maintenance

## Purpose

Keep the project memory useful as both a Markdown knowledge base and an Obsidian vault.

## Use When

- Adding, moving, or deleting memory files.
- Adding diagrams, screenshots, or other memory assets.
- Changing templates or navigation pages.
- Improving discoverability through links, backlinks, or graph structure.

## Workflow

1. Start at [../../MEMORY.md](../../MEMORY.md) and identify the authoritative memory area.
2. Use standard Markdown links so files work in GitHub, editors, and Obsidian.
3. Update index pages when adding important memory pages.
4. Store attachments under [../assets/](../assets/).
5. Keep Obsidian local workspace files ignored; do not commit per-user workspace layout.
6. Verify links after changes.

## Quality Bar

- The vault graph shows meaningful relationships rather than isolated notes.
- The same files remain readable outside Obsidian.
- Templates and attachments stay easy to find.
