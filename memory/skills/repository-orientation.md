# Skill: Repository Orientation

## Purpose

Provide a repeatable way to understand the repository before changing it.

## Use When

- Starting a new session.
- Working in an unfamiliar area.
- Investigating a bug or vague request.
- Introducing the first implementation for a new subsystem.

## Workflow

1. Read [../../MEMORY.md](../../MEMORY.md).
2. Read [../project/current-state.md](../project/current-state.md).
3. Read [../agents/working-memory.md](../agents/working-memory.md) for active context and follow-ups.
4. Read the relevant architecture, engineering, operations, or skills pages for the task.
5. Inspect the actual repository structure and implementation before making assumptions.
6. If implementation differs from memory, update memory as part of the change.

## Current Repository Notes

- The repository currently has no application source code.
- The memory system is the only established project structure.
- Technology choices are intentionally undecided until implementation begins.
