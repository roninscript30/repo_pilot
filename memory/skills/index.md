# Skills Library

Status: Active
Owner: Project Maintainers
Last Updated: 2026-08-06

Skills are reusable engineering knowledge. They are not project history.

Use this directory for stable practices that contributors and AI agents should reuse across tasks.

## Available Skills

- `frontend-ui.md` - UI, UX, accessibility, and desktop interface principles
- `react-typescript.md` - React and TypeScript practices
- `tauri-rust.md` - Tauri and Rust integration direction
- `git-provider-apis.md` - Git, GitHub, GitLab, Forgejo, Gitea, and API integration principles
- `testing-quality.md` - testing and quality practices
- `documentation-knowledge.md` - documentation and memory maintenance practices

## Adding Skills

Add or update a skill when reusable knowledge appears repeatedly.

Keep skills practical, concise, and linked to project rules.

## Online Skill Intake

External skills, examples, articles, and patterns may be incorporated when useful, but they must be adapted into project-specific guidance rather than copied blindly.

Before adding external knowledge:

- Verify it fits Repo Pilot's architecture and product philosophy.
- Prefer mature, maintained, well-understood practices.
- Record source links when the source is important.
- Avoid adding tool-specific complexity before the project needs it.

The initial skill library is seeded with project-specific guidance and links to official online references where useful. Actual tool-specific skill packages should only be installed after maintainers choose the agent/runtime system and approve the source.
